## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Ashfaq12-code/ZENVOTECH---ZEN-COMPANY-WEBSITE.git
```

Navigate to the project directory:

```bash
cd ZENVOTECH---ZEN-COMPANY-WEBSITE
```

Install dependencies:

```bash
npm install
```

Configure the required environment variables locally using `.env.local`. Never commit real credentials or API keys to GitHub.

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Deployment

Configure the production environment variables and deploy using a compatible hosting provider. The current Netlify configuration publishes the Vite production build from the `dist` directory.
